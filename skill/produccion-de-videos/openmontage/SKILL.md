# OpenMontage

Leer [README.md](README.md), [manifest.json](manifest.json) y la [licencia original](LICENSE). El código está archivado en `source.tar.gz`, no instalado.

Elegir el flujo según el material real disponible: metraje existente, imágenes, motion graphics o clips generados. No sustituir una petición de video con movimiento por una secuencia de imágenes sin explicarlo.

Para una ejecución autorizada, extraer en un entorno de trabajo separado y revisar el README, las guías y los manifiestos originales del commit fijado. Verificar Python, FFmpeg y el runtime de composición concreto; algunos componentes requieren versiones de Node distintas. Confirmar qué herramientas funcionan realmente antes de prometer el resultado.

Preparar guion, escenas y presupuesto antes de usar proveedores de pago. Conservar procedencia y permisos de música, metraje, voces y otros recursos. Mantener credenciales fuera del repositorio.

Revisar continuidad, duración, cuadros clave, subtítulos, niveles de audio y parámetros del archivo final. No presentar las pruebas internas descritas por el upstream como verificaciones ya realizadas aquí.
