## Integridad y alcance

SHA-256 de `source.tar.gz`:

`5767e3f327962354b21b028863da7d90eb1b144dfa6a7dbb466c647eed4a863c`

Los contenidos incluidos son idénticos a los del commit fijado. Solo se normalizaron los metadatos del contenedor TAR y se seleccionaron los archivos indicados en el manifiesto. No se guardan historia Git, dependencias instaladas, pesos de modelos, binarios compilados ni medios de demostración.

Para consultar el código, verificar primero el SHA-256 y extraer `source.tar.gz` en una carpeta nueva y vacía. Extraer no instala el proyecto. La instalación, las claves, las descargas de modelos y cualquier ejecución son trabajos separados. Los recursos omitidos pueden hacer falta para algunas funciones.

La instantánea oficial completa está disponible en [el commit de origen](https://github.com/deepbeepmeep/Wan2GP/tree/6479db36bdc2619a904a852bba9c2d78e1a83f82) y en [su archivo oficial](https://codeload.github.com/deepbeepmeep/Wan2GP/tar.gz/6479db36bdc2619a904a852bba9c2d78e1a83f82). Revisar `excluded_files` antes de intentar reproducir un ejemplo. No se ha realizado una auditoría exhaustiva de seguridad ni una prueba funcional del software.
