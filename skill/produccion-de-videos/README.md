# Producción de videos

Biblioteca privada de código de referencia para producir y generar video. Archivada el **10 de octubre de 2026** en `Aalvarocarrero/proyectos-web`.

## Proyectos

- **[OpenMontage](openmontage/README.md):** organiza investigación, guion, recursos, montaje y composición de un video mediante herramientas y flujos de trabajo.
- **[Wan2GP / WanGP](wan2gp/README.md):** interfaz y herramientas para ejecutar modelos generativos de video, imagen y audio, según el equipo y el modelo elegido.

Cada carpeta contiene un archivo **source.tar.gz con código real**, el README original, las licencias conservadas, una guía reutilizable y un manifiesto con el commit de origen, archivos incluidos, exclusiones y comprobaciones de integridad. Las versiones están fijadas y no se actualizan automáticamente.

## Estado y alcance

**Archivado, no instalado ni ejecutado.** No se han descargado modelos adicionales ni configurado claves, cuentas, APIs, despliegues o servicios. No se han activado GitHub Actions ni Pages.

Los archivos de código, documentación, configuración de ejemplo, pruebas y licencias conservan sus bytes originales. Se omitieron medios de demostración, imágenes, tipografías, pesos de modelos y binarios compilados. Cada exclusión está identificada en el manifiesto del proyecto y puede recuperarse del commit oficial fijado. El archivo no es un paquete listo para ejecutar y los recursos omitidos pueden ser necesarios para algunos ejemplos o funciones.

La copia de repositorios no incorpora automáticamente sus instrucciones al asistente. La entrada local [SKILL.md](SKILL.md) ayuda a elegir una herramienta y preparar un trabajo futuro sin confundir el archivo con una instalación.
