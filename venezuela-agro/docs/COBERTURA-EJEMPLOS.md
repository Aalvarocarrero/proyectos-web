# Ejemplos de aprendizaje

## Gestión privada

Las diez áreas de Mi Finca muestran una explicación propia de qué introducir, qué hacer y qué resultado revisar, con acceso directo a la sección correspondiente de la finca de práctica. La navegación no copia registros ni restablece los ejemplos editados.

| Área | Ejemplo disponible | Límite |
|---|---|---|
| Resumen | Finca ficticia y navegación entre módulos | Solo datos de práctica |
| Animales | Tres fichas únicas y diez pesajes fechados | Pesajes asociados, no animales duplicados |
| Plano y potreros | Diez usos de área, edición y croquis | No certifica linderos ni aporta cobertura satelital universal |
| Producción | Ocho ciclos editables | No registra ventas ni enlaza automáticamente parcelas |
| Planificación y costos | Dos escenarios, cinco movimientos y dos controles sanitarios | Supuestos ilustrativos, no recomendación veterinaria o garantía financiera |
| Inventario | Dieciséis artículos, dos por cada categoría base | Cantidades ficticias |
| Mis publicaciones | Dos borradores editables | No se publican ni envían a revisión |
| Sincronización | Exportación del estado de práctica | No simula recibo del servidor ni respaldo central |
| Seguridad y privacidad | Explicación de separación de datos | No simula cambios de permisos o autenticación |
| Configurar finca | Edición del nombre, superficie y objetivo ficticios | No altera la finca real |

Base incluida: una finca, 56 registros y dos borradores. El usuario puede modificar o eliminar ejemplos dentro de la práctica; recuperar la base requiere su acción explícita en Restablecer demostración. No se inspeccionó el almacenamiento del iPhone del usuario.

## Espacios públicos

Mercado Agro conserva un selector explícito «Ejemplos por categoría», además de ofertas publicadas. Sus ejemplos no representan disponibilidad, precios confirmados ni vendedores reales. Los seis ejemplos de registro de finca son vistas de referencia; el envío real exige completar datos y consentimiento. Los perfiles profesionales ficticios están identificados y no permiten contactos operativos. El ejemplo de proyecto es explicativo, no una iniciativa presentada.

No se considera probada una publicación real, entrega a terceros, importación de WhatsApp o dispositivo físico por mostrar una vista de ejemplo. Las comprobaciones automáticas y revisión del código cubren navegación, contenido base y separación de almacenes; la lectura visual en el teléfono continúa pendiente.
