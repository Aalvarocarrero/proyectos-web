## Emociones, imaginación y filosofía

«La torre de Dani» es una escena original ficticia: distintas emociones posibles, incertidumbre sobre la experiencia ajena, una pregunta abierta sobre ayudar o esperar y dos finales para dibujar fuera de pantalla. No se infiere una emoción por el rostro, no se pide hablar de vivencias personales, no hay clasificación moral ni puntuación. Es una porción acotada de la propuesta investigada «Historias para imaginar», no sus cuatro escenas ni un programa completo.

Las edades 6–8 son una hipótesis editorial acompañada, no una validación por edad. Las decisiones emocionales solo existen en el DOM durante la escena; no se serializan, no se envían, no se escriben en URL ni se recogen como analítica. Se conserva únicamente el estado ordinario de la sesión. El adulto puede conversar, señalar o elegir no responder. Para menores de tres años se conservan las guías físicas existentes.
