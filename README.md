# Proyectos web y referencias compartidas

Copia local organizada para un repositorio privado. Los cinco proyectos y el prototipo independiente están preparados. No se ha realizado ninguna subida a GitHub.

- venezuela-agro/: versión 72, aplicación y activos.
- anillos-draco/: versión 13, sitio estático y catálogo.
- rohocafe/: versión 9, sitio estático.
- aeterna-global/: última fuente guardada, versión 18. Última versión original con despliegue registrado: 17.
- aeterna-global/prototipos/scroll-cinematico/: prototipo privado separado, con todas las páginas y activos; no sustituye la versión original.
- alvaro-carrero-mentor/: versión 19, fuente, Worker, esquema y migraciones.
- skill/: trece referencias públicas, cada una con nombre propio, fuente y licencia. Archivar no significa instalar o integrar. Scroll World está pendiente de una decisión de implementación.

BACKUP-STATUS.json registra versiones y commits originales. Cada proyecto tiene BACKUP-INVENTORY.json con archivos seleccionados, tamaños, SHA-256 y exclusiones. BACKUP-FILES.json registra todas las huellas de esta preparación, salvo su propio archivo y el informe final.

No contiene historial Git, credenciales, archivos de entorno, dependencias instaladas, cachés, bases de datos privadas ni medios ajenos a los sitios. Se conservaron los activos necesarios, las licencias y los créditos. Las copias son independientes; no usan enlaces duros ni simbólicos.

Se escanearon todos los bytes de los archivos preparados con patrones de claves privadas, tokens, URLs firmadas y credenciales literales. No es una auditoría exhaustiva ni una garantía absoluta. No se ejecutaron pruebas o compilaciones pesadas. No se asignó una nueva licencia de código abierto.
