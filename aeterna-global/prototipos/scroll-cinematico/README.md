# Aeterna complete cinematic preview

Owner-private review copy of the complete existing Aeterna site. The original live site is unchanged.

All five source routes and all original assets from Aeterna savedv18 (aec998fc5abd10a6c5acd25d1b1afb24ca16fc90) are retained. Original page content, photographs, services, social destinations, gallery, booking and quotation previews, campaign assets and inactive analytics controls remain intact.

The home page adds only two enhancement imports: cinematic-preview.css and cinematic-preview.js. The progressive layer adds scroll-driven image pan/zoom, an extended sticky photographic feature, progress indicator and a motion toggle. Turning motion off returns the original layout; reduced-motion and data-saver users default to that layout. Without JavaScript, the original site remains usable. Every route receives noindex metadata and robots.txt disallows indexing for this private review.

This is photographic scroll motion, not generated 3D flight footage. No paid generation, external libraries or new tracking. Original booking and quotation previews retain their existing non-submitting behavior.

Browser and device QA status is reported separately; no claim of physical iPhone testing.
