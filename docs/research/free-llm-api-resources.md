# Catálogo de API LLM gratuitas: revisión práctica

**Revisión:** 20 de octubre de 2026. **Alcance:** índice de proveedores de [cheahjs/free-llm-api-resources](https://github.com/cheahjs/free-llm-api-resources), contrastado con documentación oficial actual para los candidatos relevantes.

No se crearon cuentas, claves, grants ni conexiones; no se hicieron llamadas de inferencia ni se transmitieron datos a proveedores. El catálogo es una lista comunitaria dinámica, no una garantía de precio, privacidad, capacidad o aptitud para producción. Su propio README recomienda no abusar de las cuotas. Cuotas, modelos y políticas cambian a menudo; volver a comprobar los términos antes de habilitar cualquier conector.

## Resumen ejecutivo

- **Mejor base para un cerebro compartido privado:** modelo local servido por [Ollama](https://ollama.com/), manteniendo memoria y documentos en una base propia y accesible con control de permisos. Local no significa “sin costo”: hace falta hardware, electricidad, copias de seguridad y proteger el servidor. Revisar la licencia de cada modelo descargado.
- **Opción cloud más práctica para prototipar:** [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/platform/pricing/), con 10.000 Neurons/día sin cargo, reinicio a las 00:00 UTC, compatibilidad OpenAI para chat y embeddings, y retención cero/no entrenamiento en inferencia estándar. La cuota no es ilimitada; varios modelos requieren método de pago. No usar datos personales de estudiantes hasta revisar DPA, avisos, edad, jurisdicción y controles de la aplicación.
- **Alternativa cloud rápida con voz:** [Groq](https://console.groq.com/docs/rate-limits), con límites gratuitos por modelo y Whisper STT. Por defecto no retiene el contenido de inferencia, aunque puede guardarlo hasta 30 días para confiabilidad/abuso salvo habilitar ZDR. Los límites varían por modelo y cuenta; el nivel gratuito no equivale a una SLA.
- **Comparación de modelos sin datos sensibles:** [OpenRouter](https://openrouter.ai/pricing), si se fija manualmente el proveedor/modelo y se considera que cada proveedor downstream tiene sus propias reglas. Cuota compartida de modelos gratis: 50 solicitudes/día y 20/minuto; 1.000/día solo después de comprar al menos $10 de créditos, por tanto esa ampliación no es gratuita.
- **No integrar la API de Gemini en un servicio dirigido a menores de 18 años o probablemente accesible por ellos.** La restricción aparece en términos oficiales y también afecta la cuota pagada. El uso gratuito fuera del EEE/Suiza/Reino Unido puede alimentar mejora de productos y revisión humana; se prohíbe enviar información sensible, confidencial o personal.
- **No rotar proveedores para esquivar límites.** Tratar 429/cuotas como condición de pausa y respetar `Retry-After`; el failover solo debe cambiar a proveedores aprobados por política y por elección explícita, nunca para eludir una cuota.

### Educación y uso en oficinas

No recomendar un servicio a menores solo porque tenga cuota gratis. La selección de proveedor para educación debe pasar una revisión independiente de edad mínima, privacidad del estudiante, aviso/consentimiento, retención, jurisdicción, subprocesadores, seguridad, contrato/DPA y licencias de modelos. Separar claramente un entorno **interno de adultos** de cualquier funcionalidad **accesible al estudiante**. Si una API tiene una prohibición explícita de apps menores de 18, no incorporarla en ese cliente ni usarla como dependencia del producto.

En oficinas o herramientas internas, usar primero datos sintéticos o de baja sensibilidad; ocultar secretos e identificadores; exigir revisión humana antes de enviar o publicar material educativo. Un proveedor “no entrena” no significa “no procesa”, “no retiene logs de servicio”, ni garantiza exactitud, derechos de autor o cumplimiento de la aplicación.

## Plan de adaptadores preparado, no activado

1. **Contrato común**: `chat`, `stream`, `embeddings`, `speech_to_text`, `text_to_speech`; declarar por adaptador base URL, modelo, parámetros soportados, región, licencia, plan, cuota, modo de facturación, política de retención/entrenamiento y nota de edad. No asumir paridad total por ser OpenAI-compatible.
2. **Implementar stubs desactivados**: `ollama-local` por defecto; `cloudflare-workers-ai` como candidato cloud; `groq` como opción secundaria de texto/STT. `openrouter` solo en perfil de comparación con datos sintéticos. No incluir Gemini en el cliente educativo.
3. **Memoria separada del modelo**: guardar recuerdos/documentos en base propia con autenticación, permisos por usuario/equipo, cifrado, exportación/eliminación y backup. Recuperar solo contexto necesario para cada llamada; nunca enviar el almacén completo al proveedor.
4. **Secretos y gastos**: claves solo en secret manager/variables de entorno protegidas, nunca en Git ni logs. Primero presupuestos y límites bajos, uso medido por modelo, corte duro al llegar a cuota/cap. El adaptador no debe crear claves ni elegir un plan automáticamente.
5. **Privacidad y clasificación**: default `local-only` para datos privados; política `no-student-identifiers` para cualquier cloud hasta revisión formal. Pruebas solo con datos sintéticos. Registrar metadatos mínimos, no prompts/respuestas.
6. **Límites respetados**: `429` detiene o pone en espera y sigue `Retry-After`; no cambiar de cuenta/proveedor automáticamente para eludir límites. Cualquier failover debe estar preaprobado, mostrar el destino/modelo y cumplir el mismo nivel de datos.
7. **Prueba antes de habilitar**: comparar un modelo básico/local con el menor modelo cloud suficiente en español, precisión, alucinaciones, latencia, accesibilidad, coste y seguridad. Usar una lista de tareas genéricas aprobada por adultos, revisión humana de contenido y prueba de borrado/controles.
